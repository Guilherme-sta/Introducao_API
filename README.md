# Centro de APIs

Projeto desenvolvido como atividade prática da disciplina de Desenvolvimento Web, consumindo APIs públicas com HTML, CSS e JavaScript.

## 📄 Páginas

- **Conversão de Criptomoedas** — Consulta o preço de pares de moedas em tempo real usando a API da Binance.
- **Busca de Cartas Yu-Gi-Oh!** — Busca informações de cartas pelo nome usando a API YGOProDeck.
- **Consulta de Clima** — Busca o clima atual e previsão de 3 dias de qualquer cidade usando a API Open-Meteo.
